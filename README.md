# NETWORKWALKSRANEETH-B084-WK4-PENETRATION_TESTING_MEDIROZAHOSPITAL
## Executive summary

In this project, I've conducted a Black-box Penetration test on my client Mediroza General Hospital. I have been instructed to conduct a security test on their web infrastructure. There were potential vulnerabilities that I've found. One is the patients' reports that were found after login into the portal without any credentials. Moreover, the login form for the patients' portal is vulnerable to SQL injections
